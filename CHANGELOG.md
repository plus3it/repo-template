### [1.3.0](https://github.com/plus3it/repo-template/releases/tag/1.3.0)

**Released**: 2026.10.26

**Summary**:

*   Adds `AGENTS.md`, which tells agents to run `make agents/sync` and read the shared Plus3 IT instructions it writes, with a `## Repository-specific` section for each repository to fill in ([#62](https://github.com/plus3it/repo-template/pull/62))
*   Adds an `AGENTS.md` step to the new-repository checklist in `README.md` ([#62](https://github.com/plus3it/repo-template/pull/62))
*   Adds a pull request link placeholder to the entry in `CHANGELOG.template.md` ([#62](https://github.com/plus3it/repo-template/pull/62))
*   Updates tardigrade-ci to 0.30.0, which adds `make agents/sync` ([#62](https://github.com/plus3it/repo-template/pull/62))
*   Updates the plus3it/actions-workflows version used by the workflows ([#61](https://github.com/plus3it/repo-template/pull/61))
